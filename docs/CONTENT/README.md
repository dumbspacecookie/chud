# Content & marketing assets

Drop-in materials for the spread playbook. Files in this dir:

| File | What it's for |
|---|---|
| [TIKTOK.md](TIKTOK.md) | 30 video hook concepts. Produce against this list. |
| [X_THREADS.md](X_THREADS.md) | 30 founder-tweet starters. Lowercase ash-voice. |
| [COLD_DMS.md](COLD_DMS.md) | 20 outreach templates (influencers, press, betas, advisors). Personalize first line. |
| [PRESS_KIT.md](PRESS_KIT.md) | One-line/three-paragraph descriptions, quotes, FAQ. Paste-ready for press DMs. |
| [APP_STORE.md](APP_STORE.md) | Store listing copy (iOS + Android), keywords, screenshot specs, review-response templates. |

## hard rules across all content
- lowercase by default
- never use the word "we" — speak as ash (founder)
- never explain mechanics — show, don't tell
- never apologize for the brand name. own it.
- read every post out loud. if it sounds like a marketing committee wrote it, rewrite.
- 1 emoji per post max, never two

## posting cadence (first 30 days)
| Surface | Cadence |
|---|---|
| TikTok | 3-5 posts/day |
| X | 2-3 posts/day, 1 build-in-public |
| IG Reels | mirror best TikToks 1-day-later |
| Discord | seed mod team, no spam posts |
| Reddit | weekly, value-add only, no link drops |
| Cold DMs | 10/day max, all personalized |

## measurement
- weekly: new waitlist signups + source breakdown (`SELECT source, COUNT(*) FROM waitlist GROUP BY source`)
- weekly: top 3 TikToks by view count, retire the format that flopped
- monthly: cold DM reply rate (target: 10%+, redo script if below)

The TikTok engine is the single highest-leverage thing on this list. Everything else is leverage on leverage.
