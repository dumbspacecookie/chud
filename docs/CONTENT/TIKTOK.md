# TikTok content library

30 hooks. Each row: format, hook, caption, sound suggestion. Produce against this list — don't film a video without picking a row.

## ground rules
- vertical 9:16, ≤30s
- first 1.5s = hook frame, no logo, no setup
- caption appears in first second
- post 3-5x/day during launch month, then 1-2x/day
- if a video flops in 2 hours, archive and post the next one — don't try to revive
- never use the brand voice in earnest — always ironic, always lowercased, never explain the mechanic

## caption rules
- always lowercase
- < 120 chars
- end with 0 or 1 emoji, never more
- include `#chud` and one of `#rizzcheck` `#auracheck` `#fyp`
- never explain mechanics in caption — let video do it

## sound strategy
TikTok algorithm rewards trending sounds. Don't use the originals — riff on whatever's trending the day you post. Use TikTok's Creative Center to find sounds in the 1k-100k usage range (sweet spot — trending but not saturated).
