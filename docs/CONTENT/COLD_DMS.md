# Cold DM templates

20 templates for outreach to influencers, press, and beta testers. Personalize the first sentence in every send — generic-feeling DMs die on arrival.

## ground rules
- never start with "Hey!" or "Hi there!" — sounds like a marketing tool
- first line must reference something they specifically posted in the last 7 days
- never send before noon their local time
- never send on Sunday
- one CTA per DM, never two
- short. 4 sentences max. they're scrolling.

## the 20

```

dropping early access + a custom mythic aura cosmetic in your handle if you want a first look. zero strings.

@chudapp
```

## sending principles
- batches of 10/day max — any more, you stop personalizing and it shows
- 30% reply rate is a great cold campaign. 10% is normal. 5% means rewrite the script.
- never sell. always offer something free that's actually free.
- never use "i'd love to". it's the marketing-tool tell.
